# 状态栏与原生行为

“状态栏”在 Magpie 中有三层；避免拿网页底部条代替系统菜单栏。

## 1. 系统菜单栏：小摘要

macOS 代码把应用图形、多个对象的 logo 和数字组合为原生状态项。图形按菜单栏 `labelColor` 单色绘制，随系统深浅背景变化。

来自 `trayimage_darwin.go` 的逻辑点参数：

| 项目 | 参数 |
|---|---|
| 对象图标 | 14pt |
| 图标 → 数字 | 3pt |
| 对象组间隔 | 8pt |
| 应用图形后间隔 | 2pt |
| 双行数字 | 9.5pt，semibold，monospacedDigit |
| 单行数字 | 11pt，medium，monospacedDigit |
| 双行间隔 | cap-height 间隔 3.5pt |
| 纯数字模式分隔 | 1pt 宽、13pt 高细线，两侧各 5pt |

每组数字右对齐，按文字测量排版。系统菜单栏高度由系统掌控，不在宿主中硬编码一个假的 22/24px 菜单栏。

原作允许隐藏应用图形、隐藏对象 logo、切换已用/剩余、选择多个统计对象。点击对象数字打开并定位相应配额卡片。多组数字是否放得下由系统决定，新产品需控制数量和长度。

迁移建议：保留“图形 + 一到两行关键数字 + 点击详情”。数字也可以是任务数、同步进度或设备指标。未知、离线、过期和真实的 0 分开表示；tooltip 或展开页说明统计窗口、单位和更新时间。

## 2. 图标下的快捷浮层

```text
产品标识                            刷新  主窗  设置
固定标签：主要对象 / 配额 / 用量 / 路由（按功能存在）
可滚动内容：
  图标  名称                  当前值  强度摘要  ›
  点击后在同组内展开字段或细节
固定底部：方案 / 更新时间 / 反馈             主窗  退出
```

- 基线宽 440；内容高度限制 220–560。文本缩放放大原生窗口，再约束到当前屏幕可用高度。`520` 是窗口创建的初始高度，不是最终固定高度。
- macOS 无边框、12pt 圆角、原生半透明背景；位置在状态项下偏移 6pt。HTML 自身用约 93% 背景 tint。
- 标题高 46；标签高 26，左右 margin 12、底部 margin 8；滚动内容横向 padding 12。
- 当前摘要行高 36，`20px + fit-content(60%) + minmax(0,1fr)` 三列、gap 10；图标 18。当前值先截断，名称尽可能保留。
- 展开区左缩进 30、top 9、bottom 12、gap 8；字段高 30、圆角 8。优先原位编辑。
- 浮层分组容器圆角 10；配额卡圆角 11、padding 10×12；配额环外径 34、内径 28，微图高 30。仅在业务需要时使用数据组件。
- 配额组名 10.5px，对象名 12.5px；数值等宽。临界状态用琥珀，普通图表多用石墨。
- 标签、header、footer 不随内容滚走。无对应能力的标签可以不存在；暂时加载失败要显示失败与恢复入口。

原作 `NSPanel` 为 non-activating，能在当前 Space / 全屏应用上展示并接受键盘。Esc 和失焦隐藏；关闭主窗口保持托盘运行，退出为独立动作。

根据目标栈实现等价行为，不复制 Wails 内部补丁。内层 picker / 菜单的 Esc 先关闭内层并把焦点还给触发器，不应同时关掉整个面板。右键菜单与左键弹层不能争抢焦点。多显示器、边缘、DPI、输入法、键盘操作需在真实宿主验证。

Windows 遵循系统托盘习惯，浮层隐藏于任务栏；Linux 原作使用不透明窗口和页面，避免半透明 WebKitGTK 滚动残影。浏览器 `backdrop-filter` 不等同原生材质，不强迫 Windows/Linux 模拟 macOS 菜单栏数字绘制。

## 3. 窗口内部：持久状态与动作反馈

**侧栏底部服务状态**

- 在“设置”下，一行高 26、11.5px 文字、gap 8。
- 7px 绿色点、周围 3px 浅绿 ring；停用为淡灰、无 ring。
- 文案包含服务含义/地址，可点击进入相关页面。
- 新业务使用“同步正常”“设备已连接”等明确短语，而非全宽、高饱和度横幅。

**操作反馈 footer**

- 独立 flex 区、min-height 28、底 padding 6；普通文字 11.5px、muted。
- 成功/错误/警告为 12.5px、500 字重胶囊，line-height 16、padding 3×10，内容高 22；圆角 999，语义色 16% 背景和 30% 内边。
- 原有高度内显示，列表不因成功消息跳动。
- 错误和警告可选中复制；需要恢复操作时，在内容附近保留错误说明，不只留下瞬间消失的反馈。
- 原作有底部悬浮 `status.lift` 变体，不同时叠加多个通知层。

技能中的 Web 样板不具备系统注册、跨 Space、真实失焦关闭、后台驻留或系统退出能力。集成宿主并验证后才能宣称原生行为完成。
