## 主窗口骨架

```text
┌─窄侧栏─────────┬─侧栏切换 · 分组 / 当前页──────────操作─┐
│ 标识 / 窗口控件 │                                          │
│ 分组名称        │ 紧凑筛选 / 页面工具（有需要时）           │
│ 图标 + 导航项   │ ┌─一个相关对象组─────────────────────┐ │
│ 选中项轻浮起    │ │ 图标 名称 / 说明     当前值   操作 │ │
│                 │ │ 细分隔线                           │ │
│                 │ │ 图标 名称 / 说明     当前值   操作 │ │
│                 │ └────────────────────────────────────┘ │
│                 │ 下一个相关对象组                         │
│ 设置            │                                          │
│ ● 服务状态      │ 底部预留反馈区                           │
└─────────────────┴──────────────────────────────────────────┘
```

- 最小主窗口 560 × 420；可随文本缩放和屏幕空间调整。
- 侧栏 CSS 默认 212，窄于 860 时为 184；可拖动值约束在 168–320，且受窗口宽度的 36% 限制。本机观测值 176 是已保存的个性化宽度，不是原作默认。
- 主侧栏行 30 高、7 圆角、水平 padding 8、图文间距 9。分组标签 11px、500 字重、上间距 14、下间距 4。导航图标常为 16，20 网格 / 1.6 线宽。
- 侧栏选中项为 card 色及 `seg-edge` 轻阴影，图标与文字为 fg。二级导航缩进、有细竖线、26px 行高。
- 顶栏一般 46 高，macOS 主窗口为 50 个原生点，需为系统窗口控件留位。面包屑约 13.5px，祖先 muted、分隔 faint、当前页 600 字重。
- 内容左右至少 16；超宽窗口内内容居中，目标最大宽度 1200。避免名称在屏幕最左、控件在最右。
- 侧栏底部固定设置与服务状态，短窗口允许自身滚动。主体滚动，标题和底部反馈稳定。
- 用户可切换为顶部导航，不把侧栏当成跨场景不可改变的要求。

## 容器、行、控件

| 元素 | 原作基线 |
|---|---|
| 分组容器 | 白底，1px 外边，12px 圆角，内部 1px 分隔 |
| 主窗口普通行 | min-height 48；padding 7px 12px 7px 14px；gap 12 |
| 主窗口对象图标 | 22 × 22；名称 13px / 500 |
| 次要说明 | 11.5px，margin-top 1；超长截断 |
| 行内选择器 | 高 25；圆角 6；左 padding 8、右 5；字 12.5 |
| 双列控件组 | 宽 350；左自适应，右 124；gap 5 |
| 弹出选项层 | 宽 320，普通 max-height 340，圆角 11，blur 24 |
| 模型选择器变体 | max-height 420；搜索行 39；选项行 34 |
| 模态框 | 宽 min(600, 可用空间)；圆角 14；头尾稳定 |

原作模型选择器可有 43px 供应商图标轨道；分类少的业务无需复制。当前值显示勾号，键盘/指针高亮与已选值区分。实现空结果、搜索、长名称截断、翻转定位和最大可用高度。

设置采用“名称 + 解释 + 右侧值/开关”。会话/日志类列表以组头和稠密行呈现，数量与费用右对齐、使用等宽数字。不要把每个指标都提升成 32px 大数字卡片。

主窗口 ≤600px 的规则将复杂 Agent 行的控件移到下一行。其他产品按容器实际宽度决定换行，避免有侧栏时仅凭 viewport 判定。工具栏空间不足时先把按钮文案收成有名称的图标，再省略面包屑祖先，最后截断当前标题。

## 排版

- 系统字体：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "Segoe UI", system-ui, sans-serif`；正文 `13px/1.4`、400。
- 路径、标识符、技术值：`ui-monospace, "SF Mono", Menlo, Consolas, monospace`，约 11.5px；数值优先 `tabular-nums`，并非所有数字都换成等宽字体。
- Windows 可用 `Segoe UI Variable Text / Segoe UI / Microsoft YaHei UI`；技术值用 `Cascadia Mono / Consolas`，中文保留雅黑 UI fallback。
- 彩色品牌图标只负责对象识别，导航工具用单色线图标。保留目标产品自己的品牌。

## 动效

| 场景 | 源码参数 |
|---|---|
| 通用响应 | `cubic-bezier(.2,.8,.2,1)`，约 160ms |
| 普通按钮按下 | scale .96；小图标按钮 .9；侧栏行不缩放 |
| 页面进入 | 240ms，透明度 + translateY(5px)；侧栏布局下偏向仅淡入 |
| 弹层出现 | 淡入 180ms；位移 ±6px + scale .94，420ms `(.16,1,.3,1)` |
| 弹层退出 | 220ms，淡出 + scale .96，回到触发方向 |
| 面板行展开/关闭 | 480 / 400ms，`(.25,.3,.1,1)`；内容延后 60ms 淡入 |
| 主题过渡 | 350ms |
| 侧栏布局切换 | 320ms，`(.42,0,.58,1)` |

只给对应状态变化加动画。支持 reduced-motion，关闭位移和缩放，保留短淡入或即时变化。不要给所有 UI 加弹簧回弹。

## 迁移建议（非上游参数）

分组由业务关系决定；每组可以是文档、连接、任务、设备或同步源。保留最常用的直接操作，其余原位展开或放进更多菜单。桌面保留密度，触屏将操作目标提升到约 44px。主窗口与快捷面板共用状态，不共用全部内容密度。
